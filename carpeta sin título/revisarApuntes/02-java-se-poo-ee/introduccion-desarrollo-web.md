## Introducción al Desarrollo Web

&nbsp;

#### ¿CÓMO FUNCIONA LA WEB?

El mundo web, en general, está representado como un conjunto de computadoras interconectadas entre sí que se relacionan o pueden relacionarse mediante diferentes protocolos sin importar la distancia a la cual se encuentren unas de otras.

Cada una de estas computadoras pueden estar ofreciendo un servicio o información para ser consumida (un servidor) como así también pueden ser consumidores de dicho servicio o información (clientes). Esta forma de interconexión donde se ofrecen servicios que pueden ser consumidos se conoce como la **arquitectura cliente servidor**.

Mediante este **protocolo HTTP**, el cliente realiza consultas (**Request**) y recibe respuestas (**Response**).

#### DIRECCIONAMIENTO WEB

Todo recurso en internet posee una dirección única que lo representa y que permite que determinados clientes puedan acceder a él. Esta dirección es comúnmente conocida como *URL (Uniform Resource Locator)*.

La URL se trata de una **«traducción» de una dirección IP** que apunta al **servidor** del cual será consumida determinada información o acceso a un servicio. Para que sea más práctico y entendible para los usuarios, se determinan las URL para poder ingresar a sitios web sin la necesidad de manejar o tener conocimiento sobre direcciones IP o redes.

&nbsp;

#### ARQUITECTURA CLIENTE-SERVIDOR

La arquitectura cliente-servidor establece que existe una serie de clientes que puede conectarse a servidores para consumir un determinado servicio. Este servicio puede ser de impresión, de correo electrónico, de base de datos, de aplicaciones, entre muchos otros. 

La principal característica de éste modelo es que un mismo servicio puede estar siendo consumido al mismo tiempo por un sin fin de clientes, siempre y cuando el servidor encargado de recibir las peticiones tenga la capacidad suficiente para tratarlas.
