Los atajos de teclado de IntelliJ IDEA varían según el sistema operativo, pero los más esenciales incluyen Ctrl+Shift+A (en Windows/Linux) o Cmd+Shift+A (en macOS) para buscar acciones, Ctrl+Alt+L (Windows/Linux) o Cmd+Alt+L (macOS) para formatear código, y Ctrl+/ (Windows/Linux) o Cmd+/ (macOS) para comentar/descomentar líneas. 

Navegación y búsqueda

- Double Shift (Shift+Shift): Busca en cualquier lugar (archivos, acciones, símbolos).
-  Ctrl+Shift+N (Windows/Linux) / Cmd+Shift+O (macOS): Busca archivos.
-  Ctrl+N (Windows/Linux) / Cmd+O (macOS): Busca clases. 
- Ctrl+Shift+E (Windows/Linux) / Cmd+E (macOS): Ve a archivos recientes.
- Ctrl+B (Windows/Linux) / Cmd+B (macOS): Navega a la declaración.


Edición y refactorización

- Alt+Enter: Muestra acciones contextuales y correcciones rápidas.
- Ctrl+D (Windows/Linux) / Cmd+D (macOS): Duplica línea.
- Ctrl+Shift+Up/Down (Windows/Linux) / Cmd+Option+Up/Down (macOS): Mueve líneas de código.
- Shift+F6 (Windows/Linux) / Cmd+F6 (macOS): Renombra variables y métodos.
- Ctrl+Alt+Shift+T (Windows/Linux) / Cmd+Option+T (macOS): Invoca refactorización.
- Ctrl+Alt+M (Windows/Linux) / Cmd+Option+M (macOS): Extrae método.
 

Depuración y ejecución

- Alt+Shift+F10 (Windows/Linux) / Ctrl+Shift+F10 (macOS): Ejecuta la clase actual.
- F7 / F8 / Shift+F8: Paso a paso (Step Into, Step Over, Step Out). 
- Ctrl+Alt+F (Windows/Linux) / Cmd+Option+F (macOS): Extrae atributo.
- 
Para configurar o cambiar estos atajos, abre el cuadro de diálogo de configuración con Ctrl+Alt+S (Windows/Linux) o Cmd+, (macOS) y selecciona Keymap.  También puedes instalar el plugin Key Promoter X para aprender los atajos mientras trabajas o imprimir una tarjeta de referencia desde Help > Keyboard Shortcuts PDF.
