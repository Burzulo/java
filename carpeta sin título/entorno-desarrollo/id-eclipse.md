  ````java
  System.out.println();
  ````

<br>

| | | |
|---:|:---:|:---|
| *Ctrl + Shift + F* | - | Formatea el código (tabulaciones, saltos de líneas …) |  
| *Ctrl + Shift + C* | - | Comentar-Descomentar con // las líneas seleccionadas |
| *Alt + Shift + S* | - | Generar Getters and Setters AUTOMATICOS |
| *Ctrl + Alt + ↑* | - | Duplica la línea actual en la línea línea superior |
| *Ctrl + Alt + ↓* | - | Duplica la línea actual en la línea línea inferior |
| *Alt + ↑* | - | Intercambia la línea actual con la línea superior |
| *Alt + ↓* | - | Intercambia la línea actual con la línea inferior |
| *Ctrl + D* | - | Elimina la línea actual (en la que se encuentra el cursor) |
| *Ctrl + Z* | - | Deshacer edición |
| *Ctrl + Y* | - | Rehacer edición |
| *Ctrl + L* | - | Ir a la línea número («introducir número») |
| *Ctrl + M* | - | Maximizar-Minimizar el panel activo |
| *Ctrl + S* | - | Guarda cambios del fichero|
| *Ctrl + Shift + P* | - | Con el cursor en un comienzo o fin de llave o paréntesis, lleva al otro extremo |
| *Ctrl + Shift + L* | - | Muestra todos los atajos del teclado |
| *Ctrl + Shift + X* | - | Convierte las letras a mayúsculas (del texto seleccionado) |
| *Ctrl + Shift + Y* | - | Convierte las letras a minúsculas (del texto seleccionado) |
|  |  |  |

<br>


—------ SIN PROBAR -----------------------------------------------------------------------------------

Ctrl + →  ➙  Saltar con el cursor una palabra completa hacia la derecha del cursor <br/>
Ctrl + ←  ➙  Saltar con el cursor una palabra completa hacia la izquierda del cursor <br/>
Alt + ←  ➙  Ir a la anterior edición (ya sea en este fichero u otro) <br/>
Alt + →  ➙  Ir a la siguiente edición (ya sea en este fichero u otro) <br/>
Alt + Shift + A  ➙  Entra/sale del modo selección en bloque (permite seleccionar regiones rectangulares para copiarlas y pegar tras salir del modo) <br/>
Ctrl + -  ➙  Comprimir bloque de llaves <br/>
Ctrl + +  ➙  Desplegar bloque de llaves <br/>
Ctrl + Shift + R  ➙  Permite abrir un fichero (del workspace) escribiendo las primeras letras de su nombre (Open Resource) aunque yo lo prefiero en la combinación Ctrl+T <br/>
Ctrl + E  ➙  Permite cambiar a una pestaña abierta escribiendo las primeras letras de su nombre (o usando las flechas) <br/>
Ctrl + Shift + S ➙  Salvar todos los ficheros con cambios <br/>
Ctrl + O  ➙  Mostrar y seleccionar métodos y atributos del fichero actual <br/>
Ctrl + Tab  ➙  Siguiente pestaña abierta (Configurar el Command ‘Next Tab’) <br/>
Ctrl + Shift + Tab  ➙  Anterior pestaña abierta (Configurar el Command ‘Previous Tab’) <br/>
