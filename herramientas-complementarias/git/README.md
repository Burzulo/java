# **GIT**

Es un **software de control de versiones** que registra los cambios realizados sobre un archivo o un conjunto de archivos a lo largo del tiempo. Git permite **gestionar distintas versiones de un mismo archivo**, pudiendo volver a una versión anterior o una más reciente cuando sea necesario.

&nbsp;
#### REPOSITORIO
Cuando se trabaja con GIT lo que se crea es un REPOSITORIO, es decir, un lugar donde se **guardan y administran** nuestros archivos.

Hay dos tipos de repositorios:

  - Locales: son aquellos que se crean de forma “local” en nuestra PC, y que no necesariamente son compartidos.
  - Remotos: son aquellos que se encuentran alojados en algún servidor externo y que puede ser accedido desde cualquier lugar. Ejemplo GitHub.git
